Registros do trabalho entregue, mantidos como estavam na tag `entrega-v1`. Os
caminhos e comandos citados aqui valem para aquela versão, não para o código atual.

| Documento | O que guarda |
| --- | --- |
| `RELATORIO.md` | O relatório, com método, resultados e limitações |
| `DIARIO.md` | Registro dia a dia, com as métricas de cada etapa |
| `RETOMAR.md` | O estado do projeto ao fim do Dia 7 |
| `ROTEIRO_ALPR_7_DIAS.md` | O plano original de 7 dias |

**Correção:** `RELATORIO.md` e `RETOMAR.md` dizem que o treino do detector de
caracteres parou por volta da época 30 de 40. O checkpoint `chars_best.pt` guarda
`epoch=38`, contada a partir de zero: são 39 épocas de 40.
